Built 2026-10-13: a YouTube edit of Tiran's screen recording of naive Claude Code run #1 (grep, prompt v1), in
`videos/caruca-naive-run-1/` (HyperFrames 0.8.155). Source recording and SRT: `~/Documents/caruca naive llm walkthrough.{mp4,srt}`
(the SRT was regenerated by Tiran and is accurate). Render goes to `~/Documents/Caruca - Naive LLM Run 1 (YouTube).mp4`.

- Rebuild: `./make.sh` regenerates scenes and `index.html` from `timeline.json` and re-runs the music carve (a rebuild wipes the carve).
  `python3 build_youtube.py` regenerates `youtube/description.txt`, `captions.en.srt`, `transcript.txt`.
- Narration voice chosen by Tiran: ElevenLabs voice id `zs057lc0shdaAFXkm2Fm`, model `eleven_multilingual_v2` (first draft used Brian; replaced).
- ElevenLabs key in the repo `.env` (observed 2026-10-13): TTS and Music work; it **lacks** `speech_to_text` and `voices_read`
  permissions; account allows **3 concurrent requests** (more returns HTTP 429).
- The source recording's audio is uneven (measured 2026-10-13 with ffmpeg loudnorm): about -38 LUFS for 0:00-2:01, -23 to -26 LUFS after; L and R channels identical. The edit plays a leveled rebuild, `assets/audio/recording_voice.m4a` (-21 LUFS per segment), with the video muted; the ffmpeg chain is in the project BRIEF.md.
- YouTube description limit is 5,000 chars; the full transcript (~7,100) does not fit, so it ships as an uploadable captions file.
